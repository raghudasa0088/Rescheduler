# My Contribution

This project was executed by a team of three, but the interactive and functional modules were designed and implemented by me.

I did not hand-write every line of code manually — instead, I worked the way modern engineers work:
I defined the logic, designed the interactions, broke down the workflows, and used iterative development with AI assistance to generate boilerplate or repetitive code. All core logic, flow, debugging, and integration were done by me.

In simple terms:
**I built the modules, and AI helped me write the lower-level code exactly the way a developer uses a junior assistant.**

---

## 1. Rescheduler (Frontend)

I designed and implemented the entire workflow:
- UI layout and structure
- Drag-and-drop interaction logic
- Slot validation rules
- Undo/reset logic
- Add Class modal flow
- Edit Professor–Course mapping flow
- Dynamic rendering structure
- API interaction logic
- Error & state-handling logic

I wrote some code directly, and used AI to accelerate repetitive JS, but the logic and architecture were fully mine.

---

## 2. Professor Leaves (Frontend)

I designed the experience and built:
- Add/edit/delete flows
- Modal-based date picker flow
- Rendering logic
- Binding with backend API
- UI validation & error states

Same workflow: logic by me, code accelerated using AI, integrated and refined manually.

## 3. Access Control (Frontend)

I designed and implemented:

## 4. Backend Contributions

I contributed logic and code to:
- Access control endpoints

Several parts of the backend were coded by AI and corrected/improved by me, but the flow, decisions, data mapping, and debugging were my work.

I handled:

## Summary

I designed the logic, workflows, integrations, UI decisions, and entire interactive behavior of the rescheduler, leaves, and access control modules.  
AI accelerated coding, but the architectural decisions, debugging, corrections, and integration were entirely done by me.

The system works end-to-end because of my decisions, not because of raw code generation.
